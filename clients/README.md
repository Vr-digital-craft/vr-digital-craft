# Instances clients

À l'étape 5, les projets et leurs fichiers sont enregistrés localement dans le navigateur afin de permettre une prévisualisation sans serveur ni publication automatique.

Le moteur utilise déjà un identifiant compatible avec la future structure `clients/<slug>/site.config.json`. L'export vers des dossiers physiques et le stockage central seront branchés sur la même structure de projet lors des étapes du back-office et du déploiement.
